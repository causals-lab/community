# Publication and licensing status

**Status: artifact-specific.** Causals Lab is accepting discussion about its public architecture. There is no single license for every Lab artifact.

These are separate decisions:

| Material | Current public position |
| --- | --- |
| Ontology specification | Intended to be public and versioned; reuse license to be selected. |
| Graph explorer | Intended to be publicly browsable; browsing does not imply bulk-download or reuse rights. |
| Graph snapshots and API | [Causals Graph v0.1.0-2026-10-09](data/v0.1.0-2026-10-09/) is downloadable under [CC BY 4.0](data/v0.1.0-2026-10-09/LICENSE_DATA.md). This grant covers that released snapshot only. The live API has no separately announced bulk-redistribution license. |
| Benchmark tasks and annotations | Intended to support research; task, answer, and test-set release rules to be selected. |
| Graph-building algorithms and operational prompts | Developed privately by the team; no source release is committed. |
| Moirai application | Separate commercial product with its own terms. |

We publish explicit terms for each released artifact rather than describing the whole project simply as “open source.” CC BY 4.0 allows reuse of rights we can grant in the released graph files; it does not license third-party news content, personal rights, the website code, or the private graph-building software. A graph edge is not necessarily a verified causal effect. Contributors should not assume that material submitted today can be incorporated into an openly licensed dataset without further review or consent. We will document the contribution terms before opening bulk contribution or annotation workflows. Send private data correction or removal requests to **data@causals.org**.
