# Publication and licensing status

**Status: draft.** Causals Lab is accepting discussion about its public architecture, but has not yet announced a general license for the graph, benchmark, or implementation.

These are separate decisions:

| Material | Current public position |
| --- | --- |
| Ontology specification | Intended to be public and versioned; reuse license to be selected. |
| Graph explorer | Intended to be publicly browsable; browsing does not imply bulk-download or reuse rights. |
| Graph snapshots and API | Release scope, attribution requirements, and license to be selected before launch. |
| Benchmark tasks and annotations | Intended to support research; task, answer, and test-set release rules to be selected. |
| Graph-building algorithms and operational prompts | Developed privately by the team; no source release is committed. |
| Moirai application | Separate commercial product with its own terms. |

We will publish explicit terms for each released artifact rather than describing the whole project simply as “open source.” Contributors should not assume that material submitted today can be incorporated into an openly licensed dataset without further review or consent. We will document the contribution terms before opening bulk contribution or annotation workflows.
